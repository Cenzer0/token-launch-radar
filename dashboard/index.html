LaunchScope

Token launch radar: pre-token protocols ranked by implied value, each with a farm plan.

The model. Implied value = TVL × 0.30 × momentum × maturity × breadth. Momentum reads the 7-day TVL change through a saturating curve (clamped to −50%..+150%), so one wild week cannot swamp the board. Maturity rewards time run with no token, on a log-age curve peaking near 22 months. Breadth adds 4% per chain the TVL already sits on, up to nine chains. A protocol joins the board only when the snapshot records no token for it and it is not a wrapped, staked or bridged product of one that already trades. The board states what a token would be worth if the protocol's record stayed as it is; it does not predict whether or when a token is issued.
